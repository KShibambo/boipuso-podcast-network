About This Project

This repository contains my individual semester project for CMPG 325. The project is a network design and implementation for Boipuso Podcast Network, a media company based in Potchefstroom that produces and edits podcast content.

The network was built in Cisco Packet Tracer and includes:

- Two sites (Head Office and Studio/Recording Facility) connected over a WAN link
- VLAN segmentation across six departments: Admin, Production, Editing, IT/Servers, Guest, and Legacy
- Single-area OSPF dynamic routing
- An ACL restricting server access to authorised departments (CR4)
- Legacy device isolation using VLAN, port security, and ACL
- Guest Wi-Fi isolated from internal networks via NAT
